Run a node

Set up a Store node or a Block Creator

Everything is open source. Pick a role, try it on the testnet first, then join mainnet with a free voucher.

What you need

Store node

Keeps encrypted copies of posts and files. Earns 80% of storage fees and 85% of bandwidth fees. The easiest way to start.

Block Creator

Confirms transactions and writes blocks of the shared ledger. Earns the fees of the blocks it writes. Needs very good uptime.

  • A machine that stays on 24/7 (VPS or home server), Linux, Windows or macOS.
  • .NET 8 SDK and git. MySQL 8 is recommended for production; without it the node stores its data in JSON files.
  • A public domain name with HTTPS in front of the node (Caddy, nginx or IIS as a reverse proxy).
  • Free disk space for the data you want to hold (Store nodes).
  • A free one-time voucher from the public list.
Get a free voucher See testnet nodes

Try everything on the testnet first: use https://testnet-api.deltanium.com and set NETWORK_ID=deltanium-test. Testnet data may be reset.

Store node

Run a Store node in 5 steps

  1. Get the code

    Clone the Store and the shared core library side by side in the same folder.

    git clone https://github.com/dlvstudio/deltanium-core.git
git clone https://github.com/dlvstudio/deltanium-store.git
cd deltanium-store

  2. Configure it

    Set these environment variables (or the same keys in appsettings / user-secrets). Never commit the voucher or your key.

    export NodeRegistration__ApiUrl="https://api.deltanium.com"
export NodeRegistration__Endpoint="https://store.your-domain.com"
export CentralApi__BaseUrl="https://api.deltanium.com"
export STORE_VOUCHER="PUBLIC-STORE-XX-XXXXXXXX"   # an unused code
# Recommended for production:
export Storage__Provider="MySql"
export ConnectionStrings__Default="Server=localhost;Database=deltanium_store;User Id=...;Password=..."
# Testnet only:
# export NETWORK_ID="deltanium-test"   (and use https://testnet-api.deltanium.com above)

  3. Put HTTPS in front

    The node listens on a local port; your reverse proxy serves it at the public HTTPS address you set as the endpoint.

    # Caddyfile example
store.your-domain.com {
    reverse_proxy localhost:5001
}

  4. Start it

    On first start the node creates its key and registers itself with the voucher.

    dotnet run -c Release --urls http://localhost:5001

  5. Check it is live

    Open the Nodes page, or ask the network directly. Your node should be listed as online.

    curl -s https://api.deltanium.com/api/explorer/nodes
curl -s https://store.your-domain.com/api/version

Block Creator

Run a Block Creator

Same idea, different variables. A Block Creator must trust the network's public keys, published on the Nodes page and in NODE_KEYS.md.

git clone https://github.com/dlvstudio/deltanium-core.git
git clone https://github.com/dlvstudio/deltanium-blocker.git
cd deltanium-blocker

export CENTRAL_API_URL="https://api.deltanium.com"
export NODE_ENDPOINT="https://blocker.your-domain.com"
export VOUCHER="PUBLIC-BLOCKER-XX-XXXXXXXX"   # an unused code
export CENTRAL_API_PUBLIC_KEY="0390329609c78fff2cd895cb3faf30b1fa868085da0e89dbeeff642258773c9191"
export SUPER_ADMIN_PUBLIC_KEY="021fd57c80fd85156c307e2f1c0bc278ea0eeabac930835ab989803ee2d77165f7"
export LISTEN_URLS="http://localhost:5003"
# Recommended: Storage__Provider=MySql and ConnectionStrings__Default=...

dotnet run -c Release

Always check these keys against NODE_KEYS.md and the Nodes page →

Optional

Add a TCP channel (DLTP)

A node can be reached over HTTPS, over TCP, or both. Browsers only use HTTPS. The desktop and mobile apps prefer TCP and fall back to HTTPS. TCP traffic uses DLTP: TLS on port 7333 with the same signed requests as HTTPS.

  1. Run the DLTP gateway

    It ships in the Store repo. It listens on port 7333, uses the TLS certificate of your HTTPS site, and forwards each request to your node. List your hosts under Gateway:Routes.

    cd deltanium-store/DltpGateway
# appsettings.json
#   "Gateway": { "Port": 7333,
#     "Routes": { "store.your-domain.com": "https://store.your-domain.com" },
#     "Certificates": { "store.your-domain.com": {
#       "Pem": "/etc/letsencrypt/live/store.your-domain.com/fullchain.pem",
#       "Key": "/etc/letsencrypt/live/store.your-domain.com/privkey.pem" } } }
# On Windows/IIS leave out "Certificates": the gateway uses the site's certificate.
dotnet publish -c Release -o /opt/deltanium-dltp
dotnet /opt/deltanium-dltp/Deltanium.DltpGateway.dll

  2. Publish the TCP address

    Set it before the node registers, and open TCP port 7333 in your firewall.

    # Store
export NodeRegistration__TcpEndpoint="tcps://store.your-domain.com:7333"
# Block Creator
export NODE_TCP_ENDPOINT="tcps://blocker.your-domain.com:7333"

A TCP-only Store cannot serve web readers. That is why every file must also have at least one replica on a Store that has HTTPS.

Keep your node key safe

  • It is your node's identityOn first start the node writes node_info.json with its private key. Whoever has it can act as your node.
  • Never commit or share itKeep node_info.json out of git and backups others can read. Make an offline copy for yourself.
  • Better: a secret, not a fileSet the key in NODE_PRIVATE_KEY from your secret store; the node then keeps no private key on disk.

If it leaks

Tell the maintainers: the old key is deactivated on Central and you register a new one. Revoked keys are listed in NODE_KEYS.md.

Getting paid

  • Fees are paid in D to your node's account (its public key), monthly for storage, after storage checks pass.
  • 1 D = 1 VND. Verified operators can cash out to VND (1% fee, from 100,000 D).
  • Node deposits and slashing are planned for a later phase and are not required now.
